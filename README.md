<h1>Calculadora de Notas Académicas – Python y Django 🐍 </h1>
Aplicación web desarrollada con Python y Django que calcula las calificaciones finales de los estudiantes basándose en porcentajes y promedios ponderados. La plataforma permite el ingreso de calificaciones, la realización de cálculos automáticos y la gestión organizada de los expedientes académicos.
